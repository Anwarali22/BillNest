2. THEORY
===============================================================================

----------------------------------------
React Component
----------------------------------------

Definition

A React Component is a reusable JavaScript function that returns JSX.

Example

function Header()
{
    return (
        <h1>BillNest Header</h1>
    );
}

A component is NOT HTML.

It is a JavaScript function that returns JSX.

----------------------------------------
Why Components Exist
----------------------------------------

Without Components

App.jsx

5000+ lines

↓

Very difficult to maintain.

With Components

Header.jsx

Navigation.jsx

Footer.jsx

ExpenseList.jsx

ExpenseItem.jsx

↓

Each file has one responsibility.

Advantages

✔ Reusable

✔ Easy to maintain

✔ Easy to debug

✔ Cleaner project structure

----------------------------------------

Reason

as a React Component.

6. REACT FRAGMENTS
===============================================================================

Short Syntax

<>

</>

Full Syntax

<React.Fragment>

</React.Fragment>

Purpose

Allows multiple elements to be grouped together without adding an extra HTML
element.

Before Fragments

<div>

    <Header />

    <Footer />

</div>

Browser Output

<div>

<h1>Header</h1>

<footer>Footer</footer>

</div>

Using Fragment

<>

    <Header />

    <Footer />

</>

Browser Output

<h1>Header</h1>

<footer>Footer</footer>

The Fragment disappears after rendering.

Think of a Fragment as an invisible wrapper used only by React.

16. INTERVIEW QUESTIONS
===============================================================================

Q1.
What is a React Component?

Answer

A React Component is a reusable JavaScript function that returns JSX.

------------------------------------------------

Q2.
Why do Component names start with a capital letter?

Answer

React distinguishes custom Components from built-in HTML elements using the
capital letter convention.

------------------------------------------------

Q3.
What is a React Fragment?

Answer

A React Fragment groups multiple JSX elements without creating an additional
DOM element.

------------------------------------------------

Q4.
Difference between Fragment and div?

Fragment

No HTML element is created.

div

Creates an actual HTML element.

------------------------------------------------

Q5.
What is an HTML Element?

Answer

A complete HTML object consisting of an opening tag, optional content, and a
closing tag (or self-closing tag).

------------------------------------------------

Q6.
What is the DOM?

Answer

The DOM (Document Object Model) is the browser's tree representation of an HTML
document, allowing JavaScript to read and modify page content.
